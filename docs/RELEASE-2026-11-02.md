# NAMQULA content and learning review — 2 November 2026

## Current delivery

All six courses, four vocabulary games, responsive phone matching, language profiles, compact AISOD Corpus credit, corpus contribution links, installable PWA and offline pack/chunk caching were already implemented and published on 1 November. They remain in this release.

This review found the principal gaps were small collections, no searchable vocabulary view, no saved word-level practice and no return-to-mistakes workflow. This release expands every collection, adds a paginated searchable word browser with topics, saves practice on the device, prioritizes due/new words, and opens flashcards for a selected topic or due-only review. Quiz and matching results, spelling practice and flashcard self-assessment all update practice history. Self-assessment/spelling schedule a one-day review; recognition intervals grow up to 14 days; mistakes return after five minutes. Corrected text invalidates previous progress for that entry without changing stable IDs.

Flashcards require revealing an answer before self-marking, offer Review again, use unbiased shuffling and describe a completed round as practised rather than mastered. Language/mode/topic route changes reset game state to prevent cross-language rounds. Navigation recognizes word collections and game routes. Corpus correction actions copy the exact entry and open the corpus separately; they do not pretend to submit an unsaved form.

## Content scope and provenance

Playable counts are generated from the packs, rather than manually maintained UI numbers: Oshikwanyama 159; Oshindonga 154; Otjiherero 37; Khoekhoegowab 84; Chokwe 36; Rukwangali 121. Total 591, up from 311. Counts include complete words and short phrases, not running-word/token totals. These are NAMQULA snapshot counts, not the size of AISOD Corpus.

The local Oshindonga dictionary is the real corpus asset AAC-TRL-00010001 visible in the corpus certification queue. Only explicitly selected records are used; Python internals, duplicate senses and duplicate answer forms are excluded. That queue displays sample assets too; none of its sample text/audio is treated as real game content or certified recordings. No reviewer level is advanced by this change.

Additions are reproducible from `scripts/vocabulary-expansion.json` through `scripts/build_language_packs.py`. Existing entry IDs and references remain intact. Every public record retains AISOD Corpus attribution, reference and rights metadata. Public profiles and gameplay keep the compact AISOD acknowledgement.

- Oshikwanyama: further complete time, travel and clothing forms in Hai ti!, PDF pages 38, 54 and 60, retaining its CC BY-SA 2.0 notice.
- Oshindonga: additional individually selected dictionary record IDs from the local corpus, retaining MIT notice and original IDs.
- Otjiherero: Herero-specific dictionary sections checked directly; daily words, weekdays and action vocabulary. Local HTML snapshot hashes are recorded for additions. `omuhona` is glossed captain as documented by its consulted entry, rather than inventing a preferred synonym.
- Khoekhoegowab: complete noun forms and unambiguous actions in the Khoekhoe Swadesh list; documented dot-separated noun endings are joined, the hyphen in hai-i is retained, and click letters/vowel marks are preserved.
- Chokwe: explicitly documented plural forms, with notes comparing singular/plural, preserving tone marks. ASJP transcription is not silently converted into learner spelling.
- Rukwangali: ordinary vocabulary facts checked against Peace Corps Namibia's Rukwangali Language Manual, PDF pages 33, 40, 42 and 47; three short conventional expressions on page 14. Spellings are retained, questionable typos/ambiguous forms are excluded. The manual's hosting/reuse terms do not establish an open licence for the training text, so additions use NOASSERTION, rather than incorrectly claiming the whole text is public domain. No illustrations, audio, exercises, cultural prose or long passages are copied. Existing storybook-derived records retain CC BY 3.0. Corpus licensing review must retain this distinction.

## Remaining work, stated explicitly

- Native-speaker editorial sign-off, authentic recordings and contextual examples across all six languages remain incomplete. Reference checking is not native-speaker certification.
- NAMQULA uses versioned bundled snapshots. A reviewed public corpus release API/export contract, access controls and synchronization are not implemented by this app-only change. No invented API or claim of instant corpus synchronization is shipped.
- Progress is local to this browser/device. Account/cloud sync, native App Store/Play Store binaries and physical smart-TV/phone testing remain separate work. The shipped mobile app is an installable PWA.
- Existing database-backed admin screens are not the release pipeline for these static packs. Production database rows, user accounts and corpus certification decisions were not modified.

## Validation

The repository tests check all six games/collections, native-language search, pagination, empty review recovery, reveal-before-self-mark behaviour, stable IDs and exact generated counts. Progress tests cover persistence, isolated languages, invalid storage, corrected text, due dates and interval limits. Offline tests cover all pack credits, cached deep links/chunks, update isolation and failed-install recovery. The pull request requires a locked install, full type check and production build. Browser proof is captured from the production build before publication.
